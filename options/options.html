AI summaries optional

Out of the box Gistly summarizes on your device and nothing leaves your computer. AI summaries read more naturally and cope with unusual wording, but they need a small proxy that you run yourself, because an API key can’t be hidden inside a browser extension. The README and installation guide walk through it, and it takes about ten minutes.

The four steps
  1. Get an Anthropic API key at console.anthropic.com.
  2. Create a free Cloudflare Worker and paste in proxy/cloudflare-worker.js from this project.
  3. Add your API key to the Worker as a secret named ANTHROPIC_API_KEY, then copy the Worker’s address.
  4. Paste that address below, press Save endpoint, allow access, then Test connection.

When this is on, only the agreement text Gistly detected (at most 12,000 characters) is sent to your proxy, never the rest of the page, and it is not stored by Gistly. If the AI is unreachable, Gistly tells you and falls back to the on-device summary.

Privacy

Gistly keeps no history of the pages you visit or the summaries it writes. The only thing it stores is the settings on this page, on this computer. Nothing is synced or sent anywhere unless you turn on AI summaries.

Gistly never clicks Accept or Reject for you. It only reads and explains.
